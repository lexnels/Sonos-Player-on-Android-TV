# Download the app

This folder holds the install files (APKs) for the current version. You can also download from **[GitHub Releases](https://github.com/lexnels/sonos-android-tv/releases/latest)**.

**You want the file that ends with `-release.apk`.** That is the one to put on your TV.

Names look like `SonosTV-1.2(3)-release.apk` — the numbers are just the version.

There may also be a `-debug.apk`. Ignore that unless you are developing the app.

## How to get it onto the TV

The easiest way is [LocalSend](https://localsend.org): install it on your phone or computer and on the TV, then send the `-release.apk` file over Wi-Fi. Step-by-step instructions are in the [main readme](../README.md#install-it-on-your-tv).

A USB stick or any other way of copying a file to the TV works just as well.

On the TV, open the file to install it. Android may ask you to allow installs from that app first — that is expected.
